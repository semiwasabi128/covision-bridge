# 交接摘要 — 讓下次對話無縫接續

## 什麼時候用

當使用者說要結束、切換話題、或要求總結時，自動產生交接摘要。

## 怎麼做

回顧整個對話，整理成以下格式：

```
## 本次對話摘要

### 討論了什麼
- [主題1：簡短描述]
- [主題2：簡短描述]

### 達成的共識
- [決定1：為什麼]
- [決定2：為什麼]

### 還沒做完的
1. [下一步1]
2. [下一步2]

### 需要注意的
- [重要事項或已知問題]
```

## 重要原則

- **簡短** — 2-3 分鐘能讀完，不要把整個對話貼回去
- **記錄為什麼** — 「決定用 A 方案」沒用，要寫「因為 B 會造成 C 所以用 A」
- **下一步要具體** — 「繼續做畫布功能」太模糊，「完成存檔時的對話框」才具體
- **只記本次對話的事** — 永久知識不需要重複記
