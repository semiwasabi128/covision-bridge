# 大腦圖譜七模式設計憲章

> v1.0 — 2026-08-19，使用者 定調：「我們要的是真實的幫助到使用者，而不是為了炫技而作的」
> 每個模式必須回答三個問題：**使用者帶著什麼問題進來？看到什麼線索？得到什麼幫助？**
> 回答不出來的模式，不准上線。

## 設計初心（Transurfing 大腦的世界觀）

大腦容器六大房間是 Transurfing 意識模型的具象：

| 房間 | 隱喻 | 內容 |
|---|---|---|
| 🌊 stream 水流軌跡 | 生命的流 | 順暢流動、重複障礙、同步性事件、能量波動 |
| 🚪 doors 門的紀錄 | 選擇的路口 | 邀請出現、門已進入、門已錯過、門在等待 |
| 🔔 pendulums 慣性鐘擺 | 外界的拉力 | 必須時刻、焦慮來源、比較目標、群體壓力 |
| 💗 heartMind 心腦對話 | 內在的聲音 | 腦說、心感、分裂時刻、整合結果 |
| ✨ fraile 頻率共振 | 能量的共振 | 讓我發光、判斷時刻、共振、偽頻率 |
| 🌉 bridges 橋樑 | 真正的成長 | 主動連結、奇異連結、時序共振、類比洞察 |

**七模式不是七種特效，是七個「走進大腦的理由」。**

---

## 模式 0：現狀全景 — 「我的大腦現在長什麼樣？」

- **使用者問題**：我最近的心力都花在哪裡？大腦整體狀態如何？
- **看到的線索**：全部記憶按房間分扇區排列，房間大小對比即生活重心對比。
- **得到的幫助**：一眼看出「我最近門開太少（都在順流）」「焦慮來源比發光時刻多」這類宏觀失衡。
- **視覺語言**：六房間扇區 + 房間色彩編碼。粒子光暈亮度=importance。

## 模式 1：能量流向 — 「我的時間/能量往哪裡流？」

- **使用者問題**：事情是怎麼演變成現在這樣的？什麼在推動什麼？
- **看到的線索**：記憶按時間排序，邊帶箭頭表示先後因果。
- **得到的幫助**：回溯脈絡——「這個決定是從哪條線發展出來的」。
- **視覺語言**：時間左→右（或按 created_at 排序）＋箭頭邊。暖色=近期、冷色=較早。
- **待改進**（現況差距）：時間染色尚未做，箭頭已有。

## 模式 2：選擇路口 — 「我面對過哪些選擇？」

- **使用者問題**：哪些門我進了、哪些我錯過了？現在還有門在等嗎？
- **看到的線索**：門房間置中放大，四種門狀態（邀請/進入/錯過/等待）色彩區分。
- **得到的幫助**：看見自己的選擇模式——「我總是錯過邀請型的門」=行為模式的鏡子。
- **視覺語言**：放射佈局（門為中心）＋金色光環。錯過的門=暗紅、等待的門=閃爍。
- **待改進**：四種門狀態的色碼還沒分化，現在全都是金色。

## 模式 3：慣性擺動 — 「什麼在拉扯我？」

- **使用者問題**：我的焦慮/比較/必須來自哪裡？哪些鐘擺在擺我？
- **看到的線索**：鐘擺房間置中，擺動動畫表示拉力方向。
- **得到的幫助**：把無形的慣性具象——「原來我這週的焦慮都連到同一個比較目標」。
- **視覺語言**：放射佈局＋搖擺動畫（swingValue 已實作）。鐘擺紅色系。
- **待改進**：只有 pendulums 房間的節點在搖，尚未依 sub_category 分化幅度。

## 模式 4：跨島聯想 — 「哪些記憶之間有奇蹟連結？」

- **使用者問題**：不同領域的記憶有沒有暗中相連？我的直覺跳躍有根據嗎？
- **看到的線索**：只保留跨房間連結（虛線），同房間的記憶淡化。
- **得到的幫助**：看見潛在的類比洞察——「我在農場學的東西原來跟投資決策同構」。
- **視覺語言**：跨房間虛線邊（已實作）＋兩端房間色各半的漸層線。
- **待改進**：漸層雙色邊未做；同房間記憶淡化未做。

## 模式 5：成長軌跡 — 「我走了多遠？」

- **使用者問題**：重要時刻怎麼累積成今天的我？
- **看到的線索**：importance≥3 的記憶按時間軸排列，星星光環標記峰值時刻。
- **得到的幫助**：低谷時回看——「三個月前我連 X 都不會，現在已經 Y」。
- **視覺語言**：水平時間軸佈局（已實作）＋星星光環（已實作）＋時間漸層背景。
- **待改進**：時間漸層背景未做；時間軸刻度未做。

## 模式 6：資產地圖 — 「我擁有哪些知識檔案？」

- **使用者問題**：我的檔案/資產怎麼跟記憶關聯？東西放哪了？
- **看到的線索**：記憶（亮粒子）＋檔案節點（淡藍小粒子）＋交叉引用連線。
- **得到的幫助**：知識管理——「這個概念我有哪些檔案支撐」＋雙擊直接開檔。
- **視覺語言**：檔案=青色小粒子（已實作）＋記憶↔檔案邊（已實作）＋雙擊開檔（本次新增）。
- **待改進**：檔案節點按 asset_kind（文檔/圖片/程式碼…）分化形狀。

## 交互總綱（七模式共用）

| 操作 | 效果 |
|---|---|
| 滾輪 | 縮放（游標錨點） |
| 拖曳 | 平移畫布／拖動節點 |
| hover | 標題浮現＋鄰居高亮、非鄰居淡出（前景/背景） |
| 單擊 | 選中：detail panel 顯示完整內容 |
| **雙擊** | **檔案節點 → 系統預設程式開啟檔案**（2026-08-19 新增） |

## 文字三層制（2026-08-19 定案）

1. 平時：sub_category 短分類（24 種）——「這是什麼類型的記憶」
2. hover：標題（content 前 20 字，剝掉固定句式）——「它在說什麼」
3. 點擊：完整內容——「全部細節」
