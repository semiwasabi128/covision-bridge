## 📐 設計原則

### 1. 語意化命名

Token 名稱應該**表達用途**，而不是表達顏色：

- ✅ 好：`textPrimary`、`accent使用者`、`surfaceElevated`
- ❌ 差：`darkGray`、`light使用者`、`medium`

### 2. 三層架構不可破

```
Widget UI → Tier Manifest → BridgeDS Token (你正在看這層)
```

### 3. 禁寫死

凡 `Color(0xFF...)`、`Colors.xxx.shadeNN` 都是違規，會被 CI 自動掃描。

### 4. 12 個分組覆蓋率

每個分組都是語意類別，**所有 token 必須歸類**。
