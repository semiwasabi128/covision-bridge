## 二、Cambridge Intelligence 三陷阱對照（我們中了哪個）

- **毛線球 Hairball**：中警——301 條語義邊在 179 節點上還好，但清灰塵後節點 7,700、邊持續增加，需要「邊聚合／重要邊優先」策略
- **暴風雪 Snowstorm**：輕微——灰塵清掉後自然解
- **星爆 Starburst**：未中——合集節點已把 4889 solo 收成二級聚攏

## 三、明確不抄

- **Roam 雙向鏈結**：我們的向量語義邊更強
- **XMind 樹狀佈局**：我們是真網絡不是樹
- **React Flow 開發者複雜度**：我們是使用者產品
- **整套換掉（Neo4j Bloom/Tldraw 整合）**：問題是進料與互動層，不是渲染引擎；自製 CustomPainter 效能已驗證

## 四、建議實施順序（等 使用者 點頭）

1. **#4 清灰塵**（半小時，收益最大，先讓圖譜變成「認得的樣子」）
2. **#2 hover 沿邊點亮＋#3 星座標示**（一起做，解「為什麼亮」）
3. **#1 葡萄串拖拽回彈**（d3 reheat 配方，手感代表作）
4. **#5 點擊彈跳＋#9 邊粗細**（低難度快速收割）
5. **#6 minimap＋#7 時間軸動畫**（節點變多後的導航層）
